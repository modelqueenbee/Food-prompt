# Food Style Profile + Meal Plan

A simple, self-contained page with two copyable prompts to help build a personal food style profile and create a practical 3-day meal plan.

## Use

Open `index.html` in a browser. Copy Part 1 into an AI chat and answer its questions. After the profile is created, copy Part 2 separately into the same conversation. If you start a new conversation, include your saved profile before Part 2.
